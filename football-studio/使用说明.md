# 足球赛前研究室 · Touchline Lab

双击同目录的 `TouchlineLab.exe` 启动 Windows 64 位便携版。它会在默认浏览器中打开本机工作台，可执行文件可以单独复制到另一台电脑。关闭桌面控制窗口即可退出服务。

## 自动收集比赛

1. 打开「赛程采集」，软件会自动获取未来 24 小时的赛程。可以修改开始、结束时间并点「采集 / 刷新赛程」。
2. 默认使用免密钥的 ESPN 公共足球赛程，采集该来源在所选范围内返回的各项赛事。页面显示实际覆盖赛事、来源时间和失败项。也可切换到 Football-Data.org，使用账户覆盖的赛程。
3. 用联赛和球队筛选，点击某场「预测此场」，或勾选多场后点击「预测已选」。点击「预测全部」会处理这次采集的全部可预测场次。进行中、已完场和开球时间待确认的比赛会显示原因。
4. 软件会重新核验赛程，并自动获取双方可用的同赛事历史赛果。需要参考赔率时勾选相应模块。结果会列出实际使用的样本数和数据缺口。
5. 每场结果可直接「播放模拟」或「查看报告」。返回采集页会保留这次赛程、筛选条件和预测结果。

球队、赛事和比赛阶段会自动显示中文。中文与原始名称一起保留，搜索框同时查找球队与赛事，支持中文全名、常用简称和原名，例如「英超」「巴甲」「曼城」「大巴黎」。赛事筛选按来源的赛事编号区分，避免不同国家的同名联赛混在一起。采集列表、预测报告及比赛演播室共用中文名称。

常用名称优先采用内置译名；赛事还会按提供方与赛事编号匹配中文名。冷门名称立即生成中文译写或音译，标注「音译待核验」，保留来源原名，随后在后台查询中文资料或翻译服务；配置了模型时也会用于批量补译。自动音译只是便于识别的临时名称，并不表示已取得官方或通行译名。网络不可用时仍可查看中文赛程，恢复后可继续补齐译名，更新名称不会清空已勾选比赛。

名称查询仅发送公开名称、类型和赛事上下文，译名缓存在本机的 `names.sqlite`。页面列出译名方式、中文资料链接及后台校正状态。更新软件后直接刷新赛程即可使用新增译名，无需删除旧记录；冻结预测保留当时的输入与来源。

点击每场的「打开比赛原网页」可回到提供方的具体比赛页面。「来源与原始数据」保留采集时间、原始队名、赛事名及原始接口地址。提供方仅返回数据接口的比赛会显示对应接口入口。导出的 HTML 和 JSON 也保留来源，便于日后复核。

赛程范围按香港时间（UTC+8）处理。公开来源的赛事覆盖与更新时间由提供方决定，页面的「全部」指本次来源实际收集的可预测比赛。采集缓存保存在本机数据目录的 `fixtures.sqlite`。

巴甲在赛事筛选中显示为「巴西甲级联赛（巴甲）」，来源原名可能是 `Brazil Serie A`。巴西当地晚间的比赛在北京时间通常是次日清晨；查找这类比赛时，请让结束时间覆盖次日，或选择「未来 3 天」再筛选赛事。

## 观看比赛动画

运行单场预测时默认开启「比赛动画」，完成后进入「比赛演播室」。也可以从工作台或报告点「播放比赛模拟」。

球场显示两队共 22 名球员的跑动、传递、抢断、射门和门将扑救。进球后更新比分，播放球员庆祝、看台动作和进球提示。点击「开启声音」可听合成的欢呼与终场哨声。

演播室支持暂停、重播、倍速、拖动进度和跳到精彩时刻。推演方式可选择最高概率比分、候选比分，或按完整比分分布抽样。抽样使用当前预测的进球均值、低比分修正及最终胜平负概率，各项输入调整后重新预测会改变抽样分布。进球分钟和球员动作属于生成的比赛演绎。

## 试算一场比赛

1. 首次打开时，工作台载入海港竞技与松林联队的虚构示例。点击「综合」或「基础」可以切换常规时间胜平负概率。
2. 点击「编辑对阵」可修改主客队、赛事、开球时间和数据截止时间。「新建空白对阵」用于录入自己的比赛。「载入演示」可恢复样例。
3. 用模块右上角的开关选择本次分析，点击模块名称填写参数。展开「查看其余模块」可选择晋级概率、外部快照、冻结预测、AI 解读等。开关变更后点击「预测并模拟」更新结果，关闭动画时按钮显示「运行预测」。
4. 在报告中查看数据截点、候选比分和已启用的结果。开启「比分矩阵」可查看各个比分格，开启「情景重算」可比较假设与基线的百分点差。报告支持导出 JSON 和 HTML。

单场对阵编辑器使用 UTC+8。比赛日、杯赛和数据查询使用相应字段标注的时区。胜平负与比分按常规时间计算，淘汰赛晋级概率单列。

## 配置大模型

打开左下角「模型设置」，填写支持 Chat Completions 的服务地址、模型 ID 和 API Key。点击「测试连接」后保存。每次测试都会向填写的模型服务发送一个简短请求。

在工作台启用「AI 解读」并运行预测，再在报告中点击「生成解读」。研究工具也能从结果面板主动发起解读。发送的内容包括本次计算结果和填写的问题。离线计算预测、模拟、回测和查看既有档案均可直接使用。

密钥默认保存在当前服务进程内。勾选「在此设备记住密钥」后，Windows 会用当前用户的凭据加密保存。模型设置与预测台账位于 `%LOCALAPPDATA%\FootballForecastStudio`。同一浏览器与本机地址会记住最近保存的单场对阵和模块选择。

## 其他研究入口

| 入口 | 可执行的工作 |
| --- | --- |
| 比赛日分析 | 编辑多场或导入赛单，计算各场预测，从不同比赛选择结果组成跨场组合 |
| 杯赛模拟 | 修改分组、Elo、已赛比分、预设落位、模拟次数和随机种子，查看晋级分布和淘汰路径 |
| 数据源 | 查询赛程、交锋、名单、伤停、评级、赔率、历史、天气、新闻和外部模型，导入或导出快照 |
| Elo 实力榜 | 从赛果生成截止某日的 Elo 排名，拟合球队攻防参数供单场预测使用 |
| 滚动回测 | 导入 CSV 或 JSON，按时间回测与验证概率校准，导出结果 |
| 预测台账 | 回看冻结输入，录入或批量导入实际比分，结算并查看赛后表现 |

使用自己的数据时，保留来源与观测时间，确保队名、主客顺序和截止时间一致。需授权的体育数据源使用各自的账户凭据，可在 Windows 用户环境变量中配置 `FOOTBALL_DATA_TOKEN`、`THE_ODDS_API_KEY` 或 `API_FOOTBALL_KEY`，然后重新启动研究室。公开历史来源和本地快照也可使用。

## 从源码运行

安装 Python 3.10 或以上版本后，在本目录运行 `python server.py --open`，可用 `--port 端口号` 指定本地端口。源码计算和服务层使用 Python 标准库。使用带 PyInstaller 6 的 Windows Python 环境运行 `python build_windows.py` 可重新打包当前页面和引擎。
